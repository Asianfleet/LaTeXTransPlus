# TUI 项目管理增强设计

## 目标

在项目管理界面增加项目多选、翻译任务终止、项目删除和重新翻译能力，并保证按钮状态和项目列表在操作或运行时事件后及时同步。

## 现状与约束

- `src/tui/app.py` 使用 Textual `DataTable` 展示所有任务下的项目。
- 翻译目前由 Textual 线程 worker 调用 `run_tui_task`；线程无法安全地被立即硬杀。
- 项目输出目录包含历史元数据 `.latextrans-tui.json`，删除输出目录即可同时删除该项目的持久化历史。
- 运行时的单个项目流程可能包含阻塞的 LLM 请求和 LaTeX 编译。

## 架构

### 独立任务子进程

每次从 TUI 启动的翻译任务在独立 `multiprocessing.Process` 中执行。子进程入口调用现有 `run_tui_task`，通过 `multiprocessing.Queue` 向主进程发送事件和最终结果。

主进程保存当前任务对应的进程句柄、事件队列和轮询 worker。轮询 worker 从队列取出事件，并使用 `call_from_thread` 将事件交给现有 `handle_runtime_event`。任务结束、异常或被终止后，主进程负责关闭队列、回收进程并刷新按钮状态。

“终止翻译”调用 `Process.terminate()`，必要时再 `join()` 回收。终止后主进程为仍处于 `running` 的项目生成 `project_cancelled` 状态事件；尚未开始的项目按同一任务输入创建 `cancelled` 项目记录，避免列表继续显示运行中。

### 项目状态

在 `ProjectStatus` 中增加 `CANCELLED = "cancelled"`。取消状态属于停止态：不再标记为运行，可删除，也可重新翻译。历史加载识别 `.latextrans-tui.json` 中的 `cancelled` 状态；没有元数据的旧目录仍按现有产物推断逻辑处理。

## 项目管理界面

### 表格

项目管理页顶部增加按钮栏，表格首列为“选中”，其后保持“项目”“状态”“任务 id”。每行使用稳定的 `(task_id, project_name)` 身份映射，单击行切换选中状态并更新首列文本 `[ ]` 或 `[√]`。刷新表格时保留仍存在项目的选中集合，删除后清理失效身份。

### 按钮启用规则

- 没有选中项目时，三个按钮全部禁用。
- “终止翻译”：仅当所有选中项目都属于正在运行的任务时启用。
- “删除”：仅当所有选中项目都不是运行状态时启用。
- “重新翻译”：仅当所有选中项目都不是运行状态时启用。

按钮状态由统一的刷新函数根据当前选中项目重新计算；运行事件、选择变化、删除、重译和终止收尾后都调用该函数。

## 操作语义

### 终止翻译

对选中运行项目所属的任务执行子进程终止。一个任务包含多个项目时，终止影响该任务的整个子进程；所有尚未完成的项目在 UI 中变为 `cancelled`。已完成项目保留完成状态。操作完成后立即刷新项目列表、任务表和按钮状态。

### 删除

对每个选中且非运行项目：若 `output_dir` 存在则递归删除该目录；随后从内存任务列表移除项目，并移除已经没有项目的任务。删除失败的项目保留在列表中并通过通知报告错误，其余项目继续处理。删除不触碰源项目目录。

### 重新翻译

对每个选中且非运行项目创建一个新的 TUI 任务。优先使用原任务的 `input_type` 与对应原始输入；历史记录若缺少可用输入类型，则回退为项目 `project_dir` 的本地输入。新任务使用新的 task id，原项目记录保留，直到新任务产生同一输出目录的运行事件后按现有历史替换逻辑去重。批量重译中的项目属于同一个新任务，避免同时启动多个子进程。

## 错误处理与清理

- 子进程无法启动、队列读取失败或运行异常时，生成任务级错误通知，并将受影响的运行项目置为 `failed` 或 `cancelled`（取决于是否由用户终止）。
- 所有结束路径都执行进程回收和队列清理，避免残留句柄。
- 删除使用明确解析后的 `output_dir`，只允许删除项目输出目录，不根据用户输入拼接任意路径。
- 终止后忽略迟到的子进程事件，防止已取消项目被旧事件改回完成或失败。

## 测试计划

- 状态模型：验证 `cancelled` 状态属于停止态，历史元数据可加载。
- 项目管理表：验证选中列、单击多选、刷新后选择保留，以及三类按钮在单选/多选和混合状态下的启用规则。
- 删除：使用临时输出目录验证目录删除、内存任务清理、部分删除失败时继续处理。
- 重译：验证原始输入优先级、历史项目本地目录回退、批量项目只创建一个新任务。
- 子进程控制：模拟进程句柄验证启动、事件转发、正常结束、异常和 `terminate()` 后的状态收尾。
- 运行现有 TUI 测试集，确认详情页、历史加载和运行事件刷新行为不回归。
