# TUI 侧栏拖动调节实现计划

**目标：** 分隔线支持左键拖动，侧栏占整体宽度的 1/8 至 1/2，仅当前会话有效。

**架构：** 在 `src/tui/sidebar.py` 中封装水平布局和可拖动分隔线；布局记录会话比例，终端缩放后重新计算字符列宽。`app.py` 只负责组合控件。

**技术：** Textual 鼠标捕获、Resize 事件、unittest 异步 Pilot。

## 实施步骤

- [x] 新增 `tests/test_tui_sidebar.py`：验证拖动、上下限、释放鼠标、终端缩放和新会话重置；真实 App 测试放在临时工作目录，隔离配置写入。
- [x] 在 latextrans 环境运行 `python -m unittest tests.test_tui_sidebar`，确认缺少拖动功能导致失败。
- [x] 新增布局与分隔线控件，替换 App 中的 Horizontal 和 Rule，并限定分隔线宽度为一列。
- [x] 运行新增测试，检查真实 UI 配置哈希和最终 diff。

实施记录：新增 3 个真实 App 异步交互测试，全部通过；初始布局重排后再开始交互。宽度断言采用包含侧栏内边距的实际区域宽度。测试前后真实 `config/ui.toml` 的 SHA256 一致。

后续修复：分隔线设置 `ALLOW_SELECT = False`，防止 Screen 在鼠标捕获前启动跨控件文本选择。新增回归测试先复现拖动选中标题的问题，再验证修复后拖动无选择且标题仍支持普通文本选择；侧栏测试共 4 个，全部通过。

## 边界约定

整体宽度使用 `#app-body` 的内容列数。最小宽度向上取整，最大宽度向下取整；初始比例为 1/5。左键释放后停止拖动，右键不启动拖动。比例只存于布局实例，不写入配置。
